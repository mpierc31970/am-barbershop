# How to: Text item

Owner-hub steps use the P3 routes; re-record when P11 completes the hub shell.

These steps are the recording script for the Remotion + Venice AI how-to videos (D110), so write every step precisely enough to record from.

Formatted text inside a column (CONT-09). Rich text has bold, italic, underline and lists, but no links: to send visitors somewhere, add a Button item.

## Activate

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | `/sign-in` | Type your **Email** and **Password**, click **Sign in** | The **Website** screen opens at `/hub/website` on the **Pages** tab |
| 2 | `/hub/website?tab=pages` | Click the page title | The page builder opens at `/hub/website/pages/[pageId]` |
| 3 | `/hub/website/pages/[pageId]` | Click a **Columns** row in the block list | The Columns form opens |
| 4 | Columns form, a column | Click **Add item**, then **Text** | A new Text item is added and its form opens with a formatting toolbar |

## Use

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | Text item form, **Text** | Type a paragraph | The text shows in the editor |
| 2 | Toolbar | Select words and click **Bold**, **Italic** or **Underline** | The words change and the button shows as pressed |
| 3 | Toolbar | Click **Bulleted list** or **Numbered list** and type the list lines | The lines show as a list |
| 4 | Text item form | Paste text copied from a web page or document | Only the allowed formatting is kept. Scripts, styles and links are removed |
| 5 | Text item form | Click **Save item** | The item row shows the first words of the text. The header reads **Draft saved · Unpublished changes** |
| 6 | Page header | Click **Preview page**, then **Publish changes** | A toast reads **Published. Your changes are live.** |
