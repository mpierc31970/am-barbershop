# How to: Divider item

Owner-hub steps use the P3 routes; re-record when P11 completes the hub shell.

These steps are the recording script for the Remotion + Venice AI how-to videos (D110), so write every step precisely enough to record from.

A thin line that separates items in a column. It has no settings (CONT-03).

## Activate

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | `/sign-in` | Type your **Email** and **Password**, click **Sign in** | The **Website** screen opens at `/hub/website` on the **Pages** tab |
| 2 | `/hub/website?tab=pages` | Click the page title | The page builder opens at `/hub/website/pages/[pageId]` |
| 3 | `/hub/website/pages/[pageId]` | Click a **Columns** row in the block list | The Columns form opens |
| 4 | Columns form, a column | Click **Add item**, then **Divider** | A Divider item is added to the column |

## Use

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | Columns form | Drag the divider between two items, or use **Move up** / **Move down** in its menu | The divider sits where you dropped it and **Saved** flashes |
| 2 | Divider item menu | Click **Delete item** | A toast reads "Divider deleted." with **Undo** for 8 seconds |
| 3 | Page header | Click **Preview page**, then **Publish changes** | A thin line shows between the items. A toast reads **Published. Your changes are live.** |
