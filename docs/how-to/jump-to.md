# How to: Jump to

These steps are the recording script for the Remotion + Venice AI how-to videos (D110), so write every step precisely enough to record from.

Jump to finds any screen, tab or help article by name, so you never have to remember where something lives. It only lists what your role can open. It searches screens and help, not your records (messages, contacts or pages by content).

## Activate

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | Any hub screen (computer) | Click **Jump to…** in the top bar, or press **Ctrl K** (Windows) / **⌘ K** (Mac) | A dialog titled **Jump to** opens with the cursor in a field reading "Search screens and help", and **Screens** lists your sidebar items and their tabs |
| 2 | Any hub screen (phone) | Tap the search icon (**Jump to**) in the header | The same dialog opens from the top, full width |

## Use

| # | Screen / route | Action | Expected result |
|---|---|---|---|
| 1 | **Jump to** | Type `pages` | The list narrows as you type; matching letters are bold. Each row shows a title and where it lives, e.g. "Website › Pages", and a count such as "3 results" |
| 2 | **Jump to** | Press **↓** twice, then **Enter** | The third result opens and the dialog closes |
| 3 | **Jump to** | Click a result | The same: the screen opens and the dialog closes. Unsaved builder edits get the builder's question first |
| 4 | **Jump to** | Type a word nothing matches, e.g. `zzz` | "Nothing matches "zzz". Try a shorter word, or open the Help center." with **open the Help center** as a link to `/hub/help` |
| 5 | **Jump to** | Press **Esc** | The dialog closes and focus goes back to where you were |
| 6 | Page builder, inside a text box | Press **Ctrl K** | Jump to does not open: in the text editor **Ctrl K** adds a link |
